# ShaMinKet — Citador Bibliográfico (Winter Edition)

Sitio web minimalista para generar citas y referencias bibliográficas de **páginas web** e **imágenes** al instante en **APA 7ª edición** y otros 5 formatos académicos (**MLA 9, Chicago 17, Harvard, IEEE y Vancouver**).

## Estilo Visual
- **Paleta Estricta ShaMinKet:** Negro obsidiana (`#060811`), azul profundo (`#0b0f1f`), azul eléctrico (`#3b82f6`) y morado (`#8b5cf6`).
- **Toque Navideño Nocturno:** Copos de nieve suaves y guirnalda de luces animadas exclusivamente en tonos azul, morado y blanco escarcha para conservar intacta la identidad visual de ShaMinKet.

## Cómo Usar
1. Haz doble clic en `abrir.command` o abre `index.html` en cualquier navegador.
2. Elige **Página Web / Artículo** o **Imagen / Fotografía**.
3. Pega el link (o pega una imagen con `Cmd + V`) y copia tu referencia en APA 7 o el formato que prefieras con un solo clic.
